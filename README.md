# Predicting High-Impact Power Outages

This is my DSC 80 Final Project. I analyze major power outage events in the United States and investigate what factors are associated with outages that affect unusually many customers.

The project uses the Power Outages dataset and follows the full data science lifecycle: data cleaning, exploratory data analysis, missingness assessment, hypothesis testing, predictive modeling, and fairness analysis.

Website: https://cookieyang888.github.io/power-outage-project/

## Files

- `index.html`: public project website
- `power_outage_project.ipynb`: analysis notebook
- `outage.xlsx`: original power outages dataset
